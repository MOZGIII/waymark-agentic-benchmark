# Design

Premises of this benchmark: what is being measured, why the setup looks the way it does, and the
decisions behind it. Not a manual for the scripts; the root README covers operation.

Reading order:

1. [goal.md](goal.md) - what is compared and on which axes
2. [fairness.md](fairness.md) - how the contest is kept fair and reproducible
3. [environment.md](environment.md) - the machines an experiment runs on
4. [lifecycle.md](lifecycle.md) - the stages of one experiment
5. [state.md](state.md) - where state and parameters live
6. [capture.md](capture.md) - what is recorded from a run
7. [budget.md](budget.md) - how a run is bounded
8. [task.md](task.md) - the sample app (not yet specified)
9. [scoring.md](scoring.md) - how results are judged (not yet designed)
10. [decisions.md](decisions.md) - dated log of choices and their reasons
